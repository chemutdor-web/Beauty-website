## Beauty Salon Website
# project Description

This project is a beauty salon website built using HTML,CSS,and javascript.it is designed to help users easily view salon services,learn more about the business,and book appointmets.

## Author
Dorcas Chemutai.

## Project Statement
Many customers find it difficult to access information about salon services and book apppointments quickly .Most small salons lack an online presence,making communication and service booking inconvinient.

## Solution
This website provides a user-friendly platform where customers can:
.View available beauty services
.Learn about the salon
.Submit appointment requests through an online form

## Objective
1. To practice HTML,CSS,and javascript skills
2. to allow users to book appointments 
3. to improve accesibility to salon services

## Technologies Used
. HTML
. CSS
.JavaScript

## Project Structure

beauty-salon
.index.html,about.html,services.html
css-style.css
js-script.js

## Features
. Appointment booking form
. Styled user interface with CSS
.Multi-page navigation (home,About,Services)

## How to run the project
1.Clone the repository
2. Open the folder in vs Code 
3. Open index.html in your browser 

## Future Improvements
. Store booking data in databases
.Enable real-time booking confirmation
.Improve UI with animations and images
